### Featured Research & Flagship Repositories

- **[clinical-tta-edge](https://github.com/NithinReddy22/clinical-tta-edge)**  
  *Unsupervised Test-Time Adaptation for Edge Vision Models.* Adapts only 10,592 normalization affine parameters (99.66% frozen backbone) under a Shannon entropy gate (tau = 0.38), cutting compute overhead by 50% to 80% on streaming video at 25.2 FPS.

- **[PatientMonitoringYOLO](https://github.com/NithinReddy22/PatientMonitoringYOLO)**  
  *Official Implementation for IEEE INSTCON 2026 & IEEE SCEECS 2026.* Real-time edge clinical patient movement tracking and fall hazard detection coupling YOLOv8 with rolling centroid Euclidean velocity tracking (F1 = 0.947) and room-context caregiver alert suppression logic.

- **[lsm_tree_cpp](https://github.com/NithinReddy22/lsm_tree_cpp)**  
  *Embedded Persistent Key-Value Storage Engine in Modern C++20.* Built from scratch with append-only Write-Ahead Logging (WAL) for crash recovery, in-memory SkipList MemTable, binary-indexed SSTables, Bloom filters, and tiered background compaction.

- **[raft_kv_store](https://github.com/NithinReddy22/raft_kv_store)**  
  *Fault-Tolerant Distributed Consensus Key-Value Store.* Implements the complete Raft consensus protocol covering randomized leader election, heartbeat RPCs, log replication, CAS transactions, and a chaos test harness simulating network partitions.
